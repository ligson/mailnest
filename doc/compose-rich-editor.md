# 写信富文本编辑器增强

## 目标与范围

写邮件、回复、回复全部和转发共用同一套编辑能力。重点解决原生 contenteditable + execCommand 和手工 Range 包裹造成的选区丢失、重复字号不生效、局部清除背景误伤其他文字、格式修改未及时进入自动草稿等问题。

本次使用 Tiptap 3.32.0 / ProseMirror 管理正文、选区、输入标记和撤销事务，不再自行拼接选区 DOM。编辑器在首次打开写信时按需加载，不增加邮件列表首屏的编辑内核下载量。

## 功能布局

默认工具栏提供撤销、重做、字体、字号、加粗、斜体、下划线、删除线、字体颜色、文字背景色、附件、图片和链接。按钮带中文提示；加粗等格式在当前选区生效时高亮。选区包含不同字体/字号时显示混合状态，而不是误报第一段格式。

「更多格式」展开：

- 正文、标题一至三，以及段落行距。
- 左对齐、居中、右对齐。
- 项目列表、编号列表、增加/减少列表层级。
- 引用、代码块、分隔线和清除格式。
- 表格插入、增删行列、合并/拆分单元格、删除表格；支持拖动列宽。
- 插入现有账号签名。

选中正文图片时显示图片宽度选择（25%、50%、75%、100%）和删除入口。继续支持选择多张图片、粘贴图片和拖入图片；沿用单张 3MB 的正文嵌图限制，较大图片仍建议作为附件。附件本身沿用原有选择与发送机制。

桌面常用工具为一行；窄屏按分组换行，不横向撑破弹框。正文独立滚动，邮件头和发送栏继续保留在可操作位置，更多格式默认折叠以保留正文空间。

## 选区与编辑行为

- 选中文字时修改只作用于所选文字；没有选区时设置后续输入格式，不插入零宽占位字符。
- 字体、字号、颜色通过 textStyle 标记直接修改，同一选区连续改字号不依赖外层 span 覆盖内层 span。
- 清除背景仅移除当前选区的背景标记，不扫描并删除共享祖先元素的样式；清除格式还会重置当前段落格式。
- ProseMirror 保存逻辑选区，工具栏下拉、色板和文件选择框不依赖长期保存的原生 Range。
- 格式事务和正文输入统一触发已有草稿脏标记/自动保存；撤销、重做同步更新正文。
- 每次新建或打开另一封草稿创建独立编辑会话，不能撤销到上一封邮件。
- 链接改为中文表单，可编辑文字、地址或移除链接；仅允许 http、https、mailto、tel，拒绝脚本、data、相对地址、控制字符和 URL 内嵌凭据。工具栏取消不修改正文。

## 数据兼容与安全

后端 API 和草稿格式保持不变，仍传 htmlBody/textBody，不将 ProseMirror JSON 存入数据库。现有附件、收件人/抄送/密送、转发附件 ID、签名和回复上下文继续使用原有接口。表格、引用、图片尺寸等基础格式写入 HTML 内联样式，不能只依赖本项目 CSS。

编辑器按支持的节点和标记解析旧 HTML；文字、常见样式、列表、表格、引用和图片继续可编辑，但它不是完整网页浏览器，不承诺逐字节保留任意历史邮件的 div/class/外链 CSS 或复杂 Office 排版。不会后台批量重写已存邮件或草稿；用户编辑、保存或发送时才序列化当前正文。后端引用内容清洗与原始邮件保留机制不变，编辑器 schema 不能代替后端安全检查。

依赖统一固定在 3.32.0，升级内核时需同步所有 Tiptap 包并回归。新增代码归入 src/modules/mail/compose，邮件页只保留轻量组件桥接。此次不改变数据库表、数据目录或 NAS 配置，也不自动发布到 NAS。

## 验收要求

1. 局部选中文字，连续改字号/字体/颜色，其他文字不变；切换光标后工具栏状态同步。
2. 部分清除已高亮文字，未选中的高亮保留；加粗、清除格式、撤销重做及键盘快捷键正常。
3. 多段选区不产生非法段落嵌套；无选区选择格式后输入，正文中无零宽占位字符。
4. 链接创建/修改/移除/取消和危险协议拒绝；表格增删、单元格操作及图片选择/缩放正常。
5. 格式变更进入草稿；恢复草稿后正文、表格和图片格式保留。模拟发送保留 To/CC/BCC 和正文，不向真实 SMTP 发测试邮件。
6. 桌面、390px 手机和矮横屏无弹框溢出；新编辑会话不复用上一封正文与撤销历史。

单元回归随 `npm run test:mail` 执行；浏览器验收使用本地模拟接口和独立浏览器会话，不操作生产邮箱。

浏览器回归脚本为 `mailnest-fe/scripts/compose-editor-browser.cjs`，供 Playwright CLI 的 run-code --filename 加载。在仓库根目录执行；先将本地 Vite 服务启动在 15174 端口（`npm run dev -- --host 127.0.0.1 --port 15174 --strictPort`），再建立独立浏览器测试会话。脚本只使用合成账号和模拟 API，禁止把 baseURL 换成生产域名或复用用户正在编辑邮件的浏览器标签页。截图写入被 Git 忽略的 output/playwright。
